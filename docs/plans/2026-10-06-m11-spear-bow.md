# M11 计划：赵云攻击体系 v2 —— 枪意四档进阶 + 箭意三档（自动双形态）

日期：2026-10-06 ｜ 前置：M10 已收口（ebad49c，365/365 绿，wx 534KB）

## 目标

普攻从「单方向小枪」升级为**波数驱动的双成长线**，可玩性提升：

- **枪意四档**（近战范围，波数自动进阶）：w1 单枪突刺 180 / w5 龙胆突刺 210 / w9 横扫枪风 240 / w13 枪圈墨波 270。伤害恒 1.0×。
- **箭意三档**（远程 320，**枪圈外无目标时自动出手**）：w1 穿云箭 单点 1.2× / w5 连珠箭 主 0.8×+溅射70 内 0.5× / w9 箭雨 主 **0.7×**+溅射110 内 0.35×。单体大伤→范围扩大→单发缩小。
- **共性放大项**：溅墨 6→14 粒、飘字 15→18px（暴击 22px 朱砂）、攻击瞬间金环脉冲、暴击 hitStop 加深（50→70ms）。
- 色系不变：墨 #1f1b16 / 鎏金 #c9a227 / 朱砂 #9e2a1e（水墨主风格）。

## 数值定稿（config.js 新增）

```js
// 枪意四档：range 为「增量」，叠加在技能算出的 atkRange 上（computeStats 的 ×1.3^range 层乘区不受影响）
export const SPEAR_STAGES = [
  { wave: 1,  bonus: 0,  fx: 'thrust' },   // 单枪突刺（现状保留）
  { wave: 5,  bonus: 30, fx: 'pierce' },   // 龙胆突刺：长枪残影+气浪
  { wave: 9,  bonus: 60, fx: 'sweep' },    // 横扫枪风：120° 扇形+鎏金飞白弧
  { wave: 13, bonus: 90, fx: 'circle' },   // 枪圈墨波：360° 枪影+射程环显形+墨波
];
export const BOW_RANGE = 320;
export const BOW_STAGES = [
  { wave: 1, kind: 'single', mul: 1.2 },
  { wave: 5, kind: 'double', mul: 0.8,  splash: { r: 70,  mul: 0.5 } },
  { wave: 9, kind: 'rain',   mul: 0.7,  splash: { r: 110, mul: 0.35 } },
];
export const BOW_FX_DUR = { draw: 0.3, fly: 0.42 }; // 拉弓/箭飞行演出时长
```

纯函数取档（engine/spear.js 新建）：`spearStageOf(wave)` 取最后一个 wave≤当前波的档；`bowStageOf(wave)` 同理。

## Engine 设计

- **heroAttack 改造**（hero.js）：
  1. `range = st.atkRange + SPEAR_STAGES[stage].bonus`（range 技能乘区保留）。
  2. targets 非空 → 枪：逻辑不变（范围全体 dealDamage；chain/slowOnHit 照旧），发事件 `{type:'heroAtk', mode:'spear', stage, ang, range, x,y(主目标)}`。
  3. targets 空 → 弓：320 内最近 1 敌为主目标，`dealDamage(atk×bowMul)`；splash 档对「半径 r 内除主目标」发 `dealDamage(splashMul)`；发 `{type:'heroAtk', mode:'bow', stage, ang, x,y, splash:{x,y,r}}`。攻速共用 atkCooldown；bow 不触发 slowOnHit（简化）；chain 仍从主目标出发。
  4. 纯函数：不改入参 state（沿用 deepClone work 模式）。
- hit/kill 事件照旧逐敌发（飘字/溅墨/击退零改动复用）。

## Render 设计

- battleFx.consume 加 `heroAtk` 分支：存 `{ mode, stage, at, ang, x, y, range, splash }`（替换现 heroAtk 单字段）；`heroAttackAnim(now)` 升级为返回该结构 + 演出时长按档（thrust 0.25 / pierce 0.5 / sweep 0.34 / circle 0.5 / bow 0.3+0.42）÷speed。
- battle.js drawHero 内按 mode+stage 分派 `drawSpearFx`（animator.js 扩展）/`drawBowFx`（battleFx 新画函数）：
  - thrust：现状枪 26px 突刺 + 放大项
  - pierce：ext 70 双层残影 + 枪尖白描气浪 + 主目标大墨花
  - sweep：120° 扇形墨浪（α≤0.16 渐隐）+ 3 道金飞白弧尾迹
  - circle：360° 枪影 5 根尾迹 + 金虚线射程环显形（半径=事件 range）+ 双圈墨波
  - bow single：拉弓 0.3 + 单箭飞行 0.42 + 命中点大墨花双环
  - bow double：主箭+0.12s 第二箭 + 溅射环显形一瞬
  - bow rain：三箭上弧散射（sin 抛物线）+ 落点墨花错落 + 大溅射环
- 金环脉冲：所有档位攻击瞬间 drawHero 外圈金环（r 24→40，α 衰减）；暴击 hitStop HIT.crit 50→70。
- 放大项：hit 分支 splash 粒子 6/10→14/18；飘字 18/23→普通 18 暴击 22（字号在 floatNum 调用处）。
