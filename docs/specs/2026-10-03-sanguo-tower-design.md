## 二、技术架构：纯函数核心 + 双容器

### 架构图

```
sanguo-tower/
├── src/
│   ├── engine/              # ★ 纯函数核心（零平台依赖，浏览器直跑）
│   │   ├── state.js         # 游戏状态机（createBattle/advanceFrame）
│   │   ├── hero.js          # 赵云行为（普攻/大招七进七出）
│   │   ├── enemy.js         # 敌人生成/移动/血量
│   │   ├── wave.js          # 波次编排（15波/章，BOSS波）
│   │   ├── items.js         # 锦囊槽8格/随机生成/三合一合成
│   │   ├── roguelike.js     # 技能池/三选一/稀有度权重
│   │   ├── combat.js        # 伤害计算/暴击/连锁/元素克制
│   │   └── meta.js          # 局外养成计算（升星/羁绊/属性加成）
│   ├── render/              # 渲染抽象层（Canvas 2D 适配）
│   │   ├── renderer.js      # 帧循环/绘制指令
│   │   ├── particles.js     # 粒子特效（双主题包A水墨/C龙形）
│   │   └── ui.js            # HUD绘制
│   ├── containers/
│   │   ├── h5/              # H5容器：index.html + dev server（开发调试）
│   │   └── wx-mini/         # 小游戏容器：game.js + game.json + 分包
│   └── assets/              # 共享素材（≤4MB，超出走分包远程加载）
├── tests/                   # Jest 单测（engine 层 100% 覆盖）
└── docs/
```

### 关键原则

1. **engine/ 是纯函数**：`advanceFrame(state, input, dt) → newState`，无 DOM/wx 依赖，Jest 全覆盖
2. **render/ 只读 state**：每帧把 state 画出来，不反向修改逻辑
3. **容器只做三件事**：注入 Canvas、桥接输入、桥接平台 API（广告/分享/存储）
4. **H5 开发流**：浏览器 DevTools 热调试 → engine 单测 → 套 wx 容器预览 → 上线

### 性能预算（微信小游戏硬指标）

| 指标 | 预算 |
|------|------|
| 首包体积 | ≤ 4MB |
| 首帧渲染 | ≤ 1.5s |
| 帧率 | 60fps（Canvas 2D，写实2D素材分层绘制无压力） |
| 内存 | ≤ 300MB |

## 三、核心玩法

### 3.1 战斗主界面（V3 视觉稿已出，写实水墨风）

```
┌─────────────────────────┐
│ 守军12/15 云八阶  金240 第八波 │  HUD：古铜镶边墨底印章牌
├─────────────────────────┤
│ ～～水墨远山（宣纸底）～～     │
│   兵       帅(精英鎏金)      │
│   ┊        ┊        弓    │  三路径虚线墨径，敌用汉字列阵
│   骑       兵        骑    │  兵/骑/弓/帅 + 血条
│        〔云〕赵云           │  居中青铜双环+鎏金光晕+朱砂「赵」印
│        (自动攻击)          │
├─────────────────────────┤
│ 青青青玄朱白▢▢ (青铜格)      │  8格锦囊槽（可合三枚朱光脉冲）
│ [锦囊][七进七出·贰][暂停]    │  大招=朱砂印章按钮（金边）
└─────────────────────────┘
```

### 3.2 局内循环（每波 5-8 分钟单局）

```
波次开始 → 敌人三路径涌入 → 赵云自动攻击
   ↑                              ↓
波次结束 ← 敌人清空/漏怪扣血 ← 玩家操作（放锦囊/合成/大招）
   ↓
肉鸽三选一 → 技能叠加 → 下一波（更强）
```

### 3.3 锦囊系统（对标遗弃之地）

| 锦囊 | 效果 | 元素 |
|------|------|------|
| 🗡️ 青龙 | 范围斩击 | 金 |
| 🛡️ 玄武 | 免伤护盾3s | 水 |
| 💨 白虎 | 范围击退 | 风 |
| 🔥 朱雀 | 持续灼烧DOT | 火 |
| 🔔 计策 | 全队攻击+30% 5s | 雷 |

- **生成**：每 6s 随机掉入空槽
- **合成**：3 张相同 → 高级锦囊（效果 ×2.5 + 附带特效）
- **上限**：8 格满员强制玩家决策（合成 or 使用 or 丢弃）
- **大招触发**：消耗 2 张「计策」锦囊

### 3.4 大招「七进七出」

- 手动释放，**2.8s 分镜演出**（七段突刺→收招冲击波→屏抖→眩晕击退）
- 演出期间时间冻结，纯演出不影响平衡
- 特效随皮肤切换：水墨·金戈（默认）/ 皮影·影窗（广告解锁）

### 3.5 肉鸽技能池（每波结束三选一）

| 稀有度 | 权重 | 示例 |
|--------|------|------|
| 普通 | 60% | 暴击+25%、攻速+15% |
| 稀有 | 30% | 攻击范围+30%、附带减速 |
| 史诗 | 10% | 连锁闪电、击杀回血、大招冷却-20% |

- 同局可叠加（构筑路线：暴击流/范围流/闪电流/大招流）
- BOSS 波前必出 1 个稀有以上

### 3.6 关卡结构

- **单章 15 波**：1-5 教学，6-10 首个 BOSS，11-15 双 BOSS 收尾
- **章节**：首版 5 章（长坂坡→赤壁→华容道→定军山→五丈原）
- **单局时长**：5-8 分钟，碎片化友好
- **失败条件**：漏怪 15 个或赵云血量归零
- **复活**：看激励视频原地复活 1 次/局

## 六、视觉规范（V3 · 写实水墨风，对标三国志战略版）

### 6.1 设计语言

- **战场**：宣纸米色渐变底（`#efe5cd→#e8dcc4→#d9c9a8`）+ 水墨远山（墨色椭圆层次 `#3a332a` 半透明叠加）+ 虚线墨径（`rgba(90,80,64,.55)`）
- **主色**：宣纸 `#e8dcc4` / 水墨墨 `#1f1b16` / 古铜 `#8b6914` / 暗金 `#c9a227` / 朱砂 `#9e2a1e`
- **面板体系**：羊皮纸卡面（`#f2e8d2→#d9c9a8` 渐变）+ 古铜双线边框（`border:2px bronze + inset paper + inset bronze-lt` 三层描边）
- **字体**：楷体 KaiTi/STKaiti 为主字体，标题加宽字距（letter-spacing 2-6px）
- **品质梯度**：UR神品（鎏金+朱砂边）/ SSR上品（描金墨底）/ SR中品（嵌玉绿 `#4a6b52`）/ R下品（素铜灰褐）
- **氛围**：水墨远山 + 宣纸雾带过渡，无霓虹无渐变流光，庄重古朴

### 6.2 核心视觉元素

| 元素 | 规格 |
|------|------|
| 敌军单位 | 墨底圆牌 + 宣纸色楷体单字（兵/骑/弓/帅），精英「帅」鎏金描边 |
| 英雄赵云 | 宣纸底青铜双环圆牌 + 墨色「云」字 + 右下朱砂「赵」小印 + 鎏金光晕 |
| 锦囊槽 | 墨底面板内青铜边小格；填充态=宣纸底墨字（青/玄/白/朱/计） |
| 大招按钮 | **朱砂印章**（`#b23a28→#9e2a1e`）+ 金边 + 内嵌宣纸描边，剩余次数以白底朱字小印「贰」标注 |
| 技能卡（三选一） | 卷轴羊皮纸卡 + 青铜双线框 + 墨字技能名 + 右侧**朱砂印章品级**（凡品灰褐/良品嵌玉/珍品朱砂，旋转 6°） |
| 武将立绘位 | 圆形墨韵渐变底 + 楷体姓氏单字（云/羽/飞/亮/超/忠），底部墨色晕影 |
| 养成详情 | 羊皮卷属性条目（中文数字：一千二百四十）+ 印章红升星按钮 |

### 6.3 交互细节

- 锦囊可合成时：三格**朱砂脉冲光**（box-shadow 呼吸）
- 大招就绪：印章红底保持常亮，未就绪转墨色
- 技能卡选中：朱砂双线框 + 微放大（scale 1.02）
- 血条：墨槽 + 鎏金填充（英雄）/ 朱砂填充（敌军）
- 敌我单位底部椭圆墨影增强立体感

### 6.4 素材规格

- 武将立绘：写实水墨人像（AI 生成 + 精修），主推图 ≤ 80KB WebP；开发期用「楷体单字圆牌」占位
  - **管线已验证**：风格锚 prompt + 赵云样张垫图，8 命武将（赵云/关羽/张飞/诸葛亮/马超/黄忠/吕布/周瑜/张辽）样张全部产出，风格一致性验收通过；母版存 `docs/samples/heroes/`（不入包），游戏内压缩至 512×768 WebP q78 ≤80KB 走 `src/assets/heroes/{heroId}.webp`
  - 展示层（抽卡/详情/主城/分享图）用 AI 立绘；战斗层维持程序化圆牌（立绘 <64px 细节失效，不用于战斗内）
- 敌军/UI：程序化绘制优先（Canvas 直接画圆牌+汉字，零图片资源）
- 边框/印章：9-slice 或程序绘制，避免整图
- 背景：水墨远山分层 2-3 张 ≤ 60KB/张，支持视差滚动
- 特效：粒子程序化生成（水墨飞白/朱砂溅墨风格），禁用序列帧

### 6.5 皮肤体系（v1.2 定案）

| 皮肤 | 获取 | 视觉体系 |
|------|------|----------|
| 写实水墨（默认） | 直接拥有 | 宣纸米底 + 墨色单位 + 朱砂点缀，本文件第六章全部规范即此皮肤 |
| 皮影戏 | 看激励视频解锁 | 暗底暖光（`#1a1410` 底 + 灯窗光晕）+ 镂空剪影单位 + 关节杆件动画（与程序化部件动画架构 1:1 契合）+ 朱砂/鎏金镂花纹样 |

- 皮肤为**整包换肤**：立绘、战斗单位配色、战场底色、粒子特效全部切换
- 技术基础：渲染层已按主题令牌化（art.js 双风格同构 API 已验证），皮肤=切换调色板+背景绘制器，engine 层零改动
