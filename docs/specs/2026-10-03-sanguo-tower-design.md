## 二、技术架构：纯函数核心 + 双容器

### 架构图

```
sanguo-tower/
├── src/
│   ├── engine/              # ★ 纯函数核心（零平台依赖，浏览器直跑）
│   │   ├── state.js         # 游戏状态机（createBattle/advanceFrame）
│   │   ├── hero.js          # 赵云行为（普攻/大招七进七出）
│   │   ├── enemy.js         # 敌人生成/移动/血量
│   │   ├── wave.js          # 波次编排（15波/章，BOSS波）
│   │   ├── items.js         # 锦囊槽8格/随机生成/三合一合成
│   │   ├── roguelike.js     # 技能池/三选一/稀有度权重
│   │   ├── combat.js        # 伤害计算/暴击/连锁/元素克制
│   │   └── meta.js          # 局外养成计算（升星/羁绊/属性加成）
│   ├── render/              # 渲染抽象层（Canvas 2D 适配）
│   │   ├── renderer.js      # 帧循环/绘制指令
│   │   ├── particles.js     # 粒子特效（双主题包A水墨/C龙形）
│   │   └── ui.js            # HUD绘制
│   ├── containers/
│   │   ├── h5/              # H5容器：index.html + dev server（开发调试）
│   │   └── wx-mini/         # 小游戏容器：game.js + game.json + 分包
│   └── assets/              # 共享素材（≤4MB，超出走分包远程加载）
├── tests/                   # Jest 单测（engine 层 100% 覆盖）
└── docs/
```

### 关键原则

1. **engine/ 是纯函数**：`advanceFrame(state, input, dt) → newState`，无 DOM/wx 依赖，Jest 全覆盖
2. **render/ 只读 state**：每帧把 state 画出来，不反向修改逻辑
3. **容器只做三件事**：注入 Canvas、桥接输入、桥接平台 API（广告/分享/存储）
4. **H5 开发流**：浏览器 DevTools 热调试 → engine 单测 → 套 wx 容器预览 → 上线

### 性能预算（微信小游戏硬指标）

| 指标 | 预算 |
|------|------|
| 首包体积 | ≤ 4MB |
| 首帧渲染 | ≤ 1.5s |
| 帧率 | 60fps（Canvas 2D，Q版2D素材无压力） |
| 内存 | ≤ 300MB |

## 三、核心玩法

### 3.1 战斗主界面（V2 视觉稿已确认）

```
┌─────────────────────────┐
│ ❤️12/15 🎖️Lv.8   🪙240 🌊8/15 │  HUD：血量/等级/金币/波次
├─────────────────────────┤
│   👹      👺(精英)       │
│   │        │        🏹   │  三路径敌人涌入（虚线金径）
│   🐘      👹        👹   │  步兵/骑兵/弓兵/精英/BOSS
│         ⚔️赵云           │  居中英雄+血条+金色光晕
│        (自动攻击)         │
├─────────────────────────┤
│ 🗡️🗡️🗡️🛡️🔥💨▢▢        │  8格锦囊槽（可合3脉冲动画）
│ [⚡技能][⚡七进七出(2)][⏸] │  大招流光渐变按钮
└─────────────────────────┘
```

### 3.2 局内循环（每波 5-8 分钟单局）

```
波次开始 → 敌人三路径涌入 → 赵云自动攻击
   ↑                              ↓
波次结束 ← 敌人清空/漏怪扣血 ← 玩家操作（放锦囊/合成/大招）
   ↓
肉鸽三选一 → 技能叠加 → 下一波（更强）
```

### 3.3 锦囊系统（对标遗弃之地）

| 锦囊 | 效果 | 元素 |
|------|------|------|
| 🗡️ 青龙 | 范围斩击 | 金 |
| 🛡️ 玄武 | 免伤护盾3s | 水 |
| 💨 白虎 | 范围击退 | 风 |
| 🔥 朱雀 | 持续灼烧DOT | 火 |
| 🔔 计策 | 全队攻击+30% 5s | 雷 |

- **生成**：每 6s 随机掉入空槽
- **合成**：3 张相同 → 高级锦囊（效果 ×2.5 + 附带特效）
- **上限**：8 格满员强制玩家决策（合成 or 使用 or 丢弃）
- **大招触发**：消耗 2 张「计策」锦囊

### 3.4 大招「七进七出」

- 手动释放，**2.8s 分镜演出**（七段突刺→收招冲击波→屏抖→眩晕击退）
- 演出期间时间冻结，纯演出不影响平衡
- 特效双主题：A 水墨·金戈（默认）/ C 史诗·龙形（看广告解锁）

### 3.5 肉鸽技能池（每波结束三选一）

| 稀有度 | 权重 | 示例 |
|--------|------|------|
| 普通 | 60% | 暴击+25%、攻速+15% |
| 稀有 | 30% | 攻击范围+30%、附带减速 |
| 史诗 | 10% | 连锁闪电、击杀回血、大招冷却-20% |

- 同局可叠加（构筑路线：暴击流/范围流/闪电流/大招流）
- BOSS 波前必出 1 个稀有以上

### 3.6 关卡结构

- **单章 15 波**：1-5 教学，6-10 首个 BOSS，11-15 双 BOSS 收尾
- **章节**：首版 5 章（长坂坡→赤壁→华容道→定军山→五丈原）
- **单局时长**：5-8 分钟，碎片化友好
- **失败条件**：漏怪 15 个或赵云血量归零
- **复活**：看激励视频原地复活 1 次/局

## 六、视觉规范（V2 已确认）

### 6.1 设计语言

- **战场**：深墨色渐变底（#3b2f2f→#1f1a1a）+ 金色虚线路径（rgba(245,197,66,0.4)）
- **主色**：金 `#f5c542` / 绛红 `#c0392b` / 墨 `#1a1a2e`
- **品质梯度**：UR金 / SSR紫 / SR蓝 / R绿
- **氛围**：底部绛红辐射光、网格纹理、英雄金色光晕

### 6.2 交互细节

- 锦囊可合成时：脉冲动画（scale 1→1.05）
- 大招就绪：三色渐变流光循环
- 技能卡 hover/选中：金边+微放大+shimmer 扫光
- 敌人：底部椭圆阴影增强立体感

### 6.3 素材规格

- 武将/敌人：Q版 2D，单帧 ≤ 15KB PNG（WebP 优先）
- 特效：粒子系统程序化生成（非序列帧），包体友好
- 背景：单图 ≤ 100KB，支持 9-slice

## 七、数据结构核心（engine 层）

```js
// 纯函数签名（engine 层全部遵循）
advanceFrame(state, inputs, dtMs) → newState

// 战斗状态（单局）
state = {
  frame, hp, coins, wave,            // 基础
  hero: { pos, hpMax, atk, buffs[] }, // 赵云
  enemies: [{ id, type, lane, pos, hp }],  // 活敌
  slots: [item|null ×8],             // 锦囊槽
  skills: [rogueSkillId ×n],         // 已选肉鸽技能
  ult: { charge, ready },            // 大招充能
  stage: 'wave' | 'skillPick' | 'over'
}

// 局外存档（wx.setStorageSync / localStorage 同构）
save = {
  heroes: { zhaoyun: { stars, level, skin } , ... },
  progress: { chapter, waveBest },
  wallet: { coins, diamonds, shards },
  daily: { signin, adsToday }
}
```
