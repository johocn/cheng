**核心循环**（一局 5~8 分钟量级）：

```
备战(锦囊/兵法) → 波次战斗(敌人三路径涌入,赵云自动攻击) → 波清
   → 肉鸽三选一技能 / BOSS 前宝箱三选一 → 下一波 ×15 → 章节通关
   → 局外结算(金币/碎片/任务/成就) → 养成变强 → 更高章节
```

## 1. 游戏设计思路

### 1.1 定位与题材

- 题材锚定赵云长坂坡「七进七出」——大招即题材名，叙事、玩法、演出三位一体。
- 美术定案**写实水墨为默认风格**（宣纸底 + 青铜边框 + 楷体 + 朱砂印章），**皮影戏为广告解锁皮肤**（暗底暖光 + 镂空剪影 + 关节杆件）；战斗演出全部纯程序化绘制，零图片资产。
- 单机向混合变现：激励视频 5 点位 + 内购 4 档。

### 1.2 对标与差异化

| 对标产品 | 借鉴点 | 我们的差异化 |
|----------|--------|-------------|
| 三国志战略版 | 写实水墨视觉体系 | 美术基调整体移植，塔防玩法差异化 |
| 城主别慌张 | 割草肉鸽循环 | 每波三选一技能 + 枪/弓双形态 |
| 遗弃之地 | 资源管理合成 | 8 格锦囊 + 三合一合成 |
| 向僵尸开炮 | 解压割草手感 | 大招「七进七出」分镜演出 |
| 保卫向日葵 | 元素连锁 | 锦囊五行元素组合 |

### 1.3 双环核心循环

- **局内环（肉鸽构筑）**：波清 → 三选一技能（9 技能池、稀有度权重、BOSS 前保底稀有）+ 锦囊三合一 + BOSS 前宝箱犒赏，一局内滚雪球。
- **局外环（卡牌养成）**：名将录 9 将收集（抽卡/章节奖励/限时活动）、升星、羁绊、皮肤；养成属性注入局内攻击乘区；章节敌方 hp 按 `1.5^(n-1)` 递增，6 章内容包循环复用。
- 两环以「金币/碎片/功勋」结算接口衔接，环环相扣。

### 1.4 四条玩法支柱

1. **波清三选一**——每波结束的构筑抉择，肉鸽核心爽点。
2. **锦囊三合一**——8 格背包的资源管理压力 + 合成升级期待感。
3. **枪/弓双形态**——近战枪意四档 + 远程箭意三档随波次自动进化，普攻本身即成长线（M11 定案）。
4. **演出即卖点**——hitStop、屏震、墨花溅射、大招分镜、Boss 卷轴，对标头部产品的表现力（M8 起持续投入）。

### 1.5 工程设计原则（设计思路的工程投影）

1. `engine/` 纯函数核心：`advanceFrame(state, input, dt) → newState`，零 DOM/wx 依赖 → 可单测、可确定性复现、双容器复用。
2. `render/` 只读 state 绘制，不反向改逻辑；演出通过消费 `frameEvents` 事件驱动，与数值结算解耦。
3. 数值全部集中在 [config.js](../../src/engine/config.js)（"平衡调整只改这里"），禁止散落硬编码。
4. 性能预算硬指标：首包 ≤4MB、首帧 ≤1.5s、60fps Canvas 2D、内存 ≤300MB。

## 2. 当前玩法总结

### 2.1 核心战斗

- **战场**：720×1280 逻辑画布竖屏，赵云居中 (360,640)，敌人沿 3 条折线路径涌入。
- **守军耐久**：`HP_MAX=15`，漏怪按敌人 `dmg` 扣减，归零战败（可复活一次）。
- **波次**：单章 15 波（`TOTAL_WAVES=15`），波内敌人成长 `×(1+(wave-1)×0.15)`；刷怪间隔 `max(0.9s, 6/count)`；BOSS 波为第 10/15 波（shuai 领衔）。
- **敌人六型**：兵(100hp)/骑(220)/弓(80)/帅(500,BOSS)/投(350,投石车驻停轰击)/藤(300,藤甲兵)；各型 speed/dmg/reward 见 [config.js](../../src/engine/config.js#L17-L24)。
- **章节包**：6 章循环（长坂坡→乌林→赤壁→华容道→荆州→成都），逐章引入投石车、藤甲兵（赤壁起）与精英词缀（词缀率 0→35%），Boss 分别为曹仁/曹休/曹真/张郃/徐晃/曹洪；章节包第 7 章起回到包 1 循环复用，敌方数值另按 `chapterMul=1.5^(n-1)` 逐章递增。
- **锦囊槽**：8 格上限，wave 阶段每 6 秒掉落一张；3 张相同合成高级（效果 ×2.5）。五型锦囊：青龙(范围斩 1.5×atk)/玄武(护盾 3s)/白虎(全场击退 t−0.12)/朱雀(灼烧 5s·每秒 2% hpMax)/计策(攻击 +30%·5s，同时是大招弹药)。

### 2.2 技能成长与抉择

**枪意四档（近战，M11 定案）**——档位随波次解锁，bonus 为射程增量叠加：

| 档 | 解锁波次 | 演出 | 效果 |
|----|---------|------|------|
| 壹 单枪突刺 | w1 | thrust（保留基础） | 基础范围攻击 |
| 贰 龙胆突刺 | w5 | 长枪残影+气浪 | 射程 +30 |
| 叁 横扫枪风 | w9 | 120° 扇形+鎏金飞白弧 | 射程 +60 |
| 肆 枪圈墨波 | w13 | 360° 枪影+射程环显形 | 射程 +90 |

**箭意三档（远程自动）**——枪圈内无目标时才出手，射程固定 320：

| 档 | 解锁波次 | 形态 | 倍率 |
|----|---------|------|------|
| 壹 穿云箭 | w1 | 单点大伤 | 1.2× |
| 贰 连珠箭 | w5 | 双发+溅射环 r70 | 主 0.8×，溅射 0.5× |
| 叁 箭雨 | w9 | 三连上弧+溅射 r110 | 主 0.7×，溅射 0.35× |

**肉鸽技能池（9 技能三稀有度）**：普通档 锋锐(暴击+25%)/疾风(攻速+15%)/砺刃(攻击+20%)，稀有档 远照(范围+30%)/凝霜(减速 30%·2s)/增垣(守军+5 回满)，史诗档 雷引(连锁 4 目标衰减 30%)/饮血(每 10 杀回 1 守军)/神机(锦囊掉落 −20%)；权重 60/30/10，BOSS 前一波（w9/w14）必出稀有以上。

**BOSS 前宝箱三选一**（M10）：w9/w14 波清 → 弹箱 → 战前犒赏；池均等无稀有概念，五选三：犒赏三军(耐久+3)/玄武庇佑(护盾 4s)/金帛犒军(金币+120)/计策入囊(随机锦囊+2)/锋芒(攻击+10% 乘区)。

**精英武印（M6+M10）**：iron 壁(hp×1.6)/swift 行(speed×1.4)/sharp 锋(漏怪 dmg+2)；出场印章演出 0.5s，同屏活跃上限 3，超出降级为头顶色点。

### 2.3 战斗反馈

- **连击**：击杀连击窗口 2 秒（`COMBO_WINDOW=2.0`），超时归零重计；漏怪清零，激励连打节奏。
- **BOSS 技能「横扫千军」**：CD 8s，前摇 1.4s（气泡台词，期间可被眩晕/击退打断），110° 扇形半径 200，命中扣 1 耐久（玄武护盾可免伤；由 2 校准为 1 保证 15 波自动通关余量）。
- **复活**：战败时可看激励视频原地满血复活，1 次/局。

### 2.4 大招「七进七出」

消耗 2 张计策锦囊手动释放 → 2.8s 分镜演出（聚气/突刺/闪光/冲击波节点，期间时间冻结）→ 结算全场 600 伤害 + 全场击退 t−0.15 + 眩晕 2s。演出与数值解耦：演出归 render（cinematic 分镜节点触发粒子/音效），结算归 engine（ult.js）。

### 2.5 外围养成

- **名将录**：9 将——赵云 UR(初始)/关羽 SSR/张飞 SSR/张辽 SSR/周瑜 SSR/诸葛亮 SR/马超 SR(章节)/黄忠 R(章节)/吕布 UR(限时)；重复转化碎片 UR15/SSR5/SR3/R1，5 星封顶每星 3 碎片；羁绊「蜀国全家福 6 人」「汉室云集 8 人(M7)」。
- **抽卡**：单抽 280 金、十连 2520（9 折）；品质权重 UR1.5/SSR8.5/SR30/R60；十连前 9 抽全 R 则第 10 抽强制 SR+；种子化 rng（mulberry32）保证可测可复现。
- **任务全家桶**（M6）：每日/每周/战令三轨；成就（M7 功勋成就）；签到、商店、体力、公告、存档齐备。

### 2.6 终局模式与商业化

- **终局三模式**（M7）：无尽挑战、每日挑战、车轮战，承接章节通关后的长线留存。
- **变现**：激励视频 5 点位（结算翻倍/免费抽卡/复活/皮影皮肤/签到）+ 内购 4 档（首充/月卡/战令/成长基金）。

## 3. 技能实现方法

### 3.1 事件驱动分层总览

技能系统的核心设计是**数值与演出分离**：

```
engine（每帧结算，产出 frameEvents: hit/kill/heroAtk/bossSkill/elite/ult…）
   ↓ 只读消费
render/battleFx.js（hitStop/飘字/屏震/粒子/音效） + cinematic.js（长演出队列）
   ↓ 底层
fx.js / particles.js（墨花、溅射、幽灵残影等原子特效）
```

engine 不关心画面，render 不改逻辑；快进/倍速时演出按 `sc` 时间缩放对齐（M12）。

### 3.2 双形态普攻引擎 — [hero.js](../../src/engine/hero.js)

- 枪形态：射程内全体受伤（近战范围定位）；攻击主循环 `heroAttack` 按 `HERO.atkInterval=0.75s` 节拍出手。
- 弓形态：枪圈内无目标时自动切弓，点射最近敌人；`bowAttack` 处理拉弓(`draw 0.3s`)/箭飞行(`fly 0.42s`)两段演出与主/溅射伤害。
- 暴击、减速（凝霜）、连锁闪电（雷引）均在此层实现；技能加成折入 `heroStat` 派生属性，范围档位增量叠加后仍走 `×1.3^range` 乘区。
- 每次出手发出 `heroAtk` 事件（携带枪/弓档位名），render 据此分派演出与音效（M11/M12）。

### 3.3 锦囊系统 — [slot.js](../../src/engine/slot.js)

`tickSlots` 按 6s 计时生成随机锦囊（8 槽满则不落）→ `useSlot` 处理：同型 3 张自动合成高级（效果 ×2.5）或直接使用，按 `kind` 分派 strike/shield/knock/burn/buff 五种效果落地到 state。

### 3.4 大招实现 — [ult.js](../../src/engine/ult.js)

检测计策持有数 ≥2 → 扣除 2 张 → 置 `state.ult` 进入演出阶段（engine 侧只推进 `ULT_CAST_DUR` 计时并冻结战场）→ 演出结束一次性结算 600 伤害/击退/眩晕。分镜节点（聚气/突刺/闪光/冲击波）由 render 的 cinematic 按时间轴触发视听反馈。

### 3.5 肉鸽技能池 — [rogue.js](../../src/engine/rogue.js)

`rollThree` 按 rarity 权重（60/30/10）抽三张不重复技能，BOSS 前一波强制保底稀有以上；`pickSkill` 写入 `state.skills` 并重算派生属性（attack/range/crit/slow/chain 等乘区链）。

### 3.6 状态机 — [state.js](../../src/engine/state.js)

`advanceFrame(state, input, dt)` 是唯一入口，stage 流转：`interval → wave → skillPick / chestPick → victory / over`；每帧依次处理输入、波次刷怪、锦囊计时、敌我攻击、死亡结算与事件产出。宝箱流转（M10）：w9/w14 波清弹箱 → 犒赏三选一 → 兵法三选一 → 开下一波；`autoPlay` 补输入供自动通关验算。

### 3.7 演出系统三层

- **battleFx**（帧级）：消费 `frameEvents`——hit 分档 hitStop（暴击/击杀加重）、飘字、屏震、溅墨（14/18px，暴击 22px）、击杀金环脉冲；M11 放大项定标 hitStop 70ms。
- **cinematic**（队列级）：长演出队列（Boss 出场卷轴、斩杀慢镜、大招分镜 v2），队列容量 2，避免长演出堵场；`reset()` 每局清队。
- **fx/particles**（原子级）：墨花、溅射环、幽灵残影、射程环等可复用特效原子；角色由 [animator.js](../../src/render/animator.js) 部件动画器驱动（纯程序化，零图片资产）。

### 3.8 打击感细节与音效接线（M12）

- 普攻音「七音配方」：枪四档走低音区 2~3 层叠加，弓三档走高音区齐射错相。
- `sfx(name, sc)` 时间缩放：快进/倍速下音效与演出同步对齐（`sc=1/speed`）。
- `heroAtk` 事件按枪/弓档位名分支出手音；hitBattle/开箱/盖章等反馈音随 M9/M10 事件接入。

## 4. 技术架构与质量

### 4.1 分层职责

| 层 | 目录 | 职责 | 约束 |
|----|------|------|------|
| 引擎 | `src/engine/` | state/hero/enemy/wave/slot/rogue/ult/combat/chest/rng/clone/config | 纯函数，零 DOM/wx 依赖 |
| 渲染 | `src/render/` | battle/battleFx/cinematic/fx/particles/animator/art/theme/ui/home/metaScreens/quests/shop/signin/result/revive/challenge/portrait 等 | 只读 state，事件驱动 |
| 局外 | `src/meta/` | heroes/gacha/quests/signin/shop/stamina/challenge/achievements/reward/notices/save/iap | 养成数值与商业化逻辑 |
| 平台 | `src/platform/` | ads/audio/iap/img/share | 平台 API 桥接，容器注入 |

### 4.2 双容器与构建

- `src/containers/h5/`：开发调试容器（vite dev server，root 指向 h5），`npm run build:h5` 产物部署静态站。
- `src/containers/wx-mini/`：微信小游戏容器（game.js/game.json），构建约 540KB。
- 英雄立绘 webp 走 public/heroes 共享。

### 4.3 测试与确定性

- vitest 全量 416 用例绿，engine 层全覆盖；`rng.js` mulberry32 种子化随机 + `clone.js` 状态深拷贝 → 同种子战斗可逐帧复现，数值改动用自动玩家（autoPlay）验算 15 波通关余量。

### 4.4 部署形态

- H5：本地 `build:h5` → tar/scp 到 odoo 服务器 openresty 站点 `/qqc/`；`game.joho.cn` 与 `game.yourbao.cn` 双域名 HTTPS，均接入游戏门户。
- 微信小游戏：wx 容器构建产物走微信开发者工具上传审核链路。
